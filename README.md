# 毛遂 · maosui

把「在招聘平台上开口」变成 agent 的一项技能。

招聘平台的招呼语是全局固定的一条——你设置一次，之后每点开一个对话都发同一句。这句话对每个 HR 都一样，信息量为零。毛遂不替换它（平台不允许），而是在它之后生成**第二条消息**：引用这份 JD 的具体要求，对应你简历里的真实经历。

不是群发工具，不是托管服务，不碰你的账号凭据。

## 三条硬承诺

- **不碰凭据** — 不存储、不代登录、不索取密码或 cookie
- **不做托管** — 没有毛遂的服务器
- **不群发** — 节流上限硬编码为「一个人手动也能做到的量」

## 使用前提

你需要一个能执行技能的 agent harness（ChatGPT / Qoder / Claude Code / DeepSeek 等）。毛遂是能力包，不是应用，没有安装器也没有 UI。

**这是真实门槛，我们不粉饰。** 第一版服务的是本来就在用 agent 的求职者。

## 风险提示

用你自己的账号、在你自己的浏览器里、由 agent 操作，**仍可能违反平台用户协议**。毛遂不声称合规（协议原文尚未查证），不替你承担风险。项目提供的降险手段是节流、逐条人工确认、不绕风控——这些降低概率，不构成免责。

v1 只做 Tier 0（agent 不接触浏览器，你自己复制粘贴），此模式下 agent 不产生任何平台可见行为，账号风险为零。

## 数据去向

毛遂自身不采集、不落库、不上报。

但你的简历和 JD 会进入你选择的 harness，此后由该 harness 的隐私政策约束。**任何跑在第三方模型上的方案都做不到「数据不出本地」**——声称做到的都是误导。毛遂能承诺的边界是：它自己不成为额外的数据出口。

## 不做什么

不代面试。不伪造经历——只允许重排、强调、按 JD 术语调整措辞；不允许新增未发生的经历、改动任何数字、调整时间线。
